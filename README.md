# できたよボード（とけい）

あさ・よるの「やること」を、**とけいを見ながら じぶんで めくる**ボードです。
字が読めない子でも使えるように、大きい絵とひらがな、アナログ時計で作っています。

**https://letters1106-code.github.io/dekitayo-board/**

ブラウザのメニューから「ホーム画面に追加」すると、アプリとして起動できます（オフラインでも開けます）。

## できること

- カードをタップで裏返す＝「できた！」。日付が変わると自動で戻る
- 時計はアナログ。**赤＝みじかいはり＝「じ」／青＝ながいはり＝「ふん」**
- カード左下のとけいマークで「よみかた」（あさの 7じ45ふん…）が出る
- 曜日ごとの出し分け、その日だけの変更、カレンダーでのふりかえり
- 「じかんに まにあったか」の演出を3段階から選べる
- マグネット用の印刷シート（PCのブラウザから）

## つかいかた

1. 右上の ⚙️ を**長押し**すると、おとなメニューが開きます
2. 「おなまえ」を入れると「〇〇の できたよボード」になります
3. 「いつもの よてい」で やることと時刻を入れかえます
4. 「設定の 書き出し／読み込み」で、べつの端末に中身を移せます

記録はその端末のブラウザの中だけに保存されます（サーバーには何も送りません）。

## 中身

単体のHTML1枚＋PWA用のファイルだけです。ビルドも外部ライブラリもありません。

- `index.html` … アプリ本体
- `manifest.json` / `sw.js` / `icons/` … ホーム画面アプリ（PWA）用
